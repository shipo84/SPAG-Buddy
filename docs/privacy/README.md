# Privacy and data protection

SPAG Buddy is used by children aged 4 to 11 in UK primary schools. These documents describe how it meets the UK GDPR, the Data Protection Act 2018 and the ICO Age Appropriate Design Code (the Children's Code).

These are working templates. They should be reviewed by the school's Data Protection Officer, and by a solicitor before SPAG Buddy is offered commercially.

## Roles

- **Controller:** the school (or the multi-academy trust). The school decides to use SPAG Buddy and which pupils take part.
- **Processor:** the SPAG Buddy operator, acting only on the school's instructions under the data processing agreement.
- **Home use without a class:** no personal data leaves the iPad, so SPAG Buddy processes nothing. The family is in control of the data on their own device.
